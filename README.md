# جعبه ابزار متنی

جعبه ابزار متنی یک ابزار سبک و مبتنی بر مرورگر برای پردازش سریع متن، فشرده‌سازی ساده کدهای CSS و JavaScript و اصلاح متن‌هایی است که با چینش اشتباه کیبورد تایپ شده‌اند.

هسته اصلی پروژه در یک فایل HTML اجرا می‌شود، به سرور یا نصب وابستگی نیاز ندارد و داده‌های واردشده را برای پردازش به بیرون ارسال نمی‌کند.

## نسخه فعلی

**نسخه 1.4.0**

## ویژگی‌ها

* پاکسازی متن فارسی
* تبدیل نیم‌فاصله به فاصله معمولی
* حذف کاراکترهای مخفی و نامرئی
* حذف فاصله‌های اضافه
* نمایش آمار تغییرات انجام‌شده روی متن
* فشرده‌سازی ساده کدهای CSS
* فشرده‌سازی ساده کدهای JavaScript
* اصلاح متن انگلیسی تایپ‌شده با چینش فارسی
* اصلاح متن فارسی تایپ‌شده با چینش انگلیسی
* تشخیص و تنظیم جهت نمایش ورودی و خروجی اصلاح کیبورد
* دکمه‌های سریع برای کپی، پیست و پاک‌کردن
* حالت روشن و تاریک
* ذخیره تم انتخاب‌شده در مرورگر
* رابط کاربری راست‌به‌چپ و مناسب زبان فارسی
* طراحی واکنش‌گرا برای موبایل و دسکتاپ
* نمایش تاریخچه تغییرات در پنجره داخلی
* اجرای کامل پردازش‌ها در مرورگر

## کاربردها

این ابزار برای کارهای روزمره توسعه، تولید محتوا و ویرایش متن مناسب است؛ از جمله:

* پاکسازی متن‌های کپی‌شده از وب‌سایت‌ها، فایل‌های PDF یا پیام‌رسان‌ها
* حذف فاصله‌های اضافی و کاراکترهای نامرئی
* آماده‌سازی سریع متن فارسی برای انتشار
* فشرده‌سازی سریع و سبک CSS یا JavaScript
* تبدیل متن‌هایی که ناخواسته با کیبورد انگلیسی تایپ شده‌اند به فارسی
* تبدیل متن‌هایی که ناخواسته با کیبورد فارسی تایپ شده‌اند به انگلیسی
* اصلاح سریع متن بدون تغییر دستی زبان کیبورد
* استفاده به‌عنوان یک ابزار کمکی سبک برای توسعه و تولید محتوا

## بخش‌های ابزار

رابط کاربری ابزار شامل سه تب اصلی است:

* `پاکسازی متن`
* `Minifier (CSS/JS)`
* `اصلاح کیبورد`

### 1. پاکسازی متن

در این بخش، متن ورودی پردازش می‌شود و نسخه پاکسازی‌شده آن در قسمت خروجی نمایش داده می‌شود.

عملیات انجام‌شده:

* تبدیل کاراکتر نیم‌فاصله `U+200C` به فاصله معمولی
* حذف کاراکترهای مخفی شامل:

  * `U+200B` — Zero Width Space
  * `U+200D` — Zero Width Joiner
  * `U+FEFF` — Byte Order Mark
* تبدیل چند فاصله متوالی به یک فاصله
* نمایش تعداد نیم‌فاصله‌های تبدیل‌شده
* نمایش تعداد فاصله‌های اضافه حذف‌شده
* نمایش تعداد کاراکترهای مخفی حذف‌شده

#### نمونه

ورودی:

```text
این‌یک   متن آزمایشی است.
```

خروجی:

```text
این یک متن آزمایشی است.
```

پس از اجرای عملیات، تعداد تغییرات انجام‌شده نیز در سه بخش مجزا نمایش داده می‌شود.

### 2. فشرده‌سازی کد

این بخش برای Minify کردن ساده کدهای CSS و JavaScript استفاده می‌شود.

کاربر می‌تواند از منوی انتخاب نوع کد، یکی از گزینه‌های زیر را انتخاب کند:

* `CSS`
* `JavaScript`

#### فشرده‌سازی CSS

در حالت CSS، ابزار عملیات زیر را انجام می‌دهد:

* حذف کامنت‌های چندخطی CSS
* کاهش فاصله‌ها و خطوط خالی
* تبدیل چند فاصله متوالی به یک فاصله
* حذف فاصله‌های غیرضروری اطراف علائم رایج

علائم پردازش‌شده شامل موارد زیر هستند:

```text
{ } : ; ,
```

نمونه ورودی:

```css
/* Main button */
.button {
  color: white;
  background: blue;
}
```

خروجی:

```css
.button{color:white;background:blue;}
```

#### فشرده‌سازی JavaScript

در حالت JavaScript، ابزار عملیات زیر را انجام می‌دهد:

* حذف کامنت‌های چندخطی
* حذف کامنت‌های تک‌خطی
* کاهش فاصله‌ها و خطوط خالی
* تبدیل چند فاصله متوالی به یک فاصله
* حذف فاصله‌های غیرضروری اطراف برخی عملگرها و علائم رایج

نمونه ورودی:

```javascript
// Show message
function showMessage() {
  console.log("Hello");
}
```

خروجی تقریبی:

```javascript
function showMessage(){console.log("Hello");}
```

> توجه: Minifier جاوااسکریپت این پروژه ساده و مبتنی بر عبارت‌های منظم یا Regex است. برای پروژه‌های Production یا کدهای پیچیده بهتر است از ابزارهایی مانند `Terser`، `esbuild` یا `SWC` استفاده شود.

### 3. اصلاح کیبورد

این بخش متن‌هایی را اصلاح می‌کند که به‌دلیل انتخاب اشتباه زبان کیبورد تایپ شده‌اند.

در نسخه 1.4.0 تبدیل در هر دو جهت پشتیبانی می‌شود:

* تبدیل متن انگلیسی تایپ‌شده با چینش اشتباه به فارسی
* تبدیل متن فارسی تایپ‌شده با چینش اشتباه به انگلیسی

دو دکمه در این بخش وجود دارد:

* `تبدیل به فارسی`
* `تبدیل به انگلیسی`

جهت نمایش خروجی نیز متناسب با نوع تبدیل تنظیم می‌شود:

* خروجی فارسی به‌صورت راست‌به‌چپ
* خروجی انگلیسی به‌صورت چپ‌به‌راست

#### تبدیل انگلیسی به فارسی

ورودی:

```text
sghl
```

خروجی:

```text
سلام
```

نمونه‌های دیگر:

```text
;hvd
```

خروجی:

```text
کاری
```

ورودی:

```text
nvdh
```

خروجی:

```text
دریا
```

#### تبدیل فارسی به انگلیسی

ممکن است هنگام فعال‌بودن کیبورد فارسی، قصد تایپ یک کلمه انگلیسی را داشته باشید.

ورودی:

```text
اثممخ
```

خروجی:

```text
hello
```

ورودی:

```text
شححمث
```

خروجی:

```text
apple
```

تبدیل‌ها براساس جایگاه کلیدهای کیبورد فارسی و انگلیسی انجام می‌شوند و حروفی که در نقشه تبدیل وجود نداشته باشند، بدون تغییر در خروجی باقی می‌مانند.

## دکمه‌های کمکی

هر بخش شامل فیلد ورودی، دکمه اجرای عملیات، فیلد خروجی و دکمه‌های کمکی است.

### پاک‌کردن

دکمه `پاک کردن` به‌صورت هم‌زمان:

* محتوای ورودی را پاک می‌کند.
* محتوای خروجی را پاک می‌کند.
* در بخش پاکسازی متن، آمار تغییرات را به صفر برمی‌گرداند.

### پیست

دکمه `پیست` متن موجود در Clipboard را می‌خواند و داخل فیلد ورودی قرار می‌دهد.

مرورگر ممکن است پیش از دسترسی به Clipboard از کاربر اجازه بخواهد.

### کپی

دکمه `کپی` محتوای فیلد خروجی را در Clipboard قرار می‌دهد.

پس از کپی موفق، متن دکمه برای مدت کوتاهی به پیام زیر تغییر می‌کند:

```text
✅ کپی شد
```

## حالت تاریک و روشن

ابزار از دو تم پشتیبانی می‌کند:

* حالت روشن
* حالت تاریک

کاربر می‌تواند با استفاده از دکمه موجود در سربرگ، بین دو حالت جابه‌جا شود.

تم انتخاب‌شده در `localStorage` ذخیره می‌شود و در بازدیدهای بعدی به‌صورت خودکار اعمال خواهد شد.

کلید ذخیره‌شده:

```text
theme
```

مقادیر ممکن:

```text
light
dark
```

در حالت تاریک، رنگ پس‌زمینه، متن، کادرها، تب‌ها و دکمه‌ها با استفاده از متغیرهای CSS تغییر می‌کنند.

## تاریخچه تغییرات

دکمه `آخرین تغییرات` در سربرگ، یک پنجره داخلی یا Modal را باز می‌کند که تاریخچه نسخه‌های پروژه را نمایش می‌دهد.

پنجره تاریخچه با روش‌های زیر بسته می‌شود:

* کلیک روی دکمه بستن
* کلیک روی فضای خارج از محتوای پنجره

## نحوه اجرا

برای اجرای پروژه کافی است فایل HTML اصلی را در یک مرورگر مدرن باز کنید:

```text
index.html
```

نیازی به موارد زیر نیست:

* نصب پکیج
* اجرای دستور Build
* اجرای سرور
* نصب Node.js
* نصب کتابخانه یا فریم‌ورک
* اتصال به پایگاه داده

بااین‌حال، قابلیت‌های مستقیم Clipboard ممکن است هنگام اجرای فایل با پروتکل `file://` در بعضی مرورگرها محدود باشند. در چنین شرایطی می‌توان پروژه را با یک سرور محلی ساده یا روی HTTPS اجرا کرد.

## ساختار پروژه

هسته اصلی ابزار می‌تواند در یک فایل HTML نگهداری شود.

ساختار فعلی یا ساده پیشنهادی:

```text
text-toolbox/
├── index.html
├── README.md
└── font.css
```

فایل `font.css` برای تعریف فونت محلی استفاده می‌شود. در صورت حذف فونت سفارشی، ابزار می‌تواند با فونت‌های سیستمی نیز اجرا شود.

در صورت توسعه بیشتر، می‌توان ساختار پروژه را به شکل زیر تفکیک کرد:

```text
text-toolbox/
├── index.html
├── README.md
├── assets/
│   └── fonts/
├── css/
│   ├── font.css
│   └── style.css
└── js/
    └── app.js
```

## فناوری‌های استفاده‌شده

## رابط کاربری

رابط کاربری به‌صورت راست‌به‌چپ طراحی شده و شامل قسمت‌های زیر است:

* سربرگ
* دکمه تغییر تم
* دکمه مشاهده تاریخچه تغییرات
* سه تب اصلی
* کادرهای ورود و خروج متن
* دکمه‌های اجرای عملیات
* دکمه‌های کپی، پیست و پاک‌کردن
* بخش نمایش آمار پاکسازی
* فوتر اطلاعات توسعه‌دهنده

در بخش اصلاح کیبورد، جهت فیلدها به‌صورت خودکار یا متناسب با زبان خروجی تنظیم می‌شود.

در نمایشگرهای کوچک، دکمه‌های تبدیل به فارسی و انگلیسی به‌صورت عمودی نمایش داده می‌شوند تا استفاده از ابزار در موبایل راحت‌تر باشد.

## طراحی واکنش‌گرا

رابط کاربری برای موبایل و دسکتاپ طراحی شده است.

در نمایشگرهایی با عرض کمتر از `600px`:

* چیدمان سربرگ عمودی می‌شود.
* اندازه متن تب‌ها کاهش پیدا می‌کند.
* اندازه آمارها متناسب با صفحه کوچک‌تر می‌شود.
* دکمه‌های اصلاح کیبورد به‌صورت عمودی نمایش داده می‌شوند.

## حریم خصوصی

این ابزار به‌صورت کامل در مرورگر کاربر اجرا می‌شود.

* متن‌ها به هیچ سروری ارسال نمی‌شوند.
* تمام پردازش‌ها به‌صورت Local انجام می‌شوند.
* اطلاعات ورودی و خروجی در پایگاه داده ذخیره نمی‌شوند.
* تنها داده ذخیره‌شده، وضعیت تم انتخاب‌شده در `localStorage` است.
* برای کپی و پیست از Clipboard API مرورگر استفاده می‌شود.
* پروژه برای عملکرد اصلی خود به سرویس پردازش خارجی نیاز ندارد.

## نکات توسعه

در صورت توسعه پروژه، بهتر است منطق پردازش متن از DOM جدا شود تا تست‌پذیری افزایش پیدا کند.

نمونه ساختار پیشنهادی:

```javascript
function normalizeText(input) {
  return {
    output: '',
    stats: {
      zwnj: 0,
      hidden: 0,
      spaces: 0
    }
  };
}
```

همچنین می‌توان منطق اصلاح کیبورد را به یک تابع مستقل تبدیل کرد:

```javascript
function convertKeyboardLayout(input, characterMap) {
  return [...input]
    .map((character) => characterMap[character] ?? character)
    .join('');
}
```

مزایای این رویکرد:

* تست‌نویسی ساده‌تر
* جداسازی منطق از رابط کاربری
* نگهداری آسان‌تر پروژه
* امکان استفاده مجدد از توابع در محیط‌های دیگر
* کاهش وابستگی توابع پردازش به عناصر HTML
* امکان افزودن تبدیل‌های جدید بدون تغییر مستقیم رابط کاربری
