# جعبه ابزار متنی

جعبه ابزار متنی یک ابزار سبک و تک‌فایلی برای پردازش سریع متن، فشرده‌سازی ساده کدهای CSS و JavaScript، و اصلاح متن‌هایی است که با چینش اشتباه کیبورد تایپ شده‌اند.

این پروژه کاملا سمت مرورگر اجرا می‌شود، به سرور نیاز ندارد و هیچ داده‌ای را برای پردازش به بیرون ارسال نمی‌کند.

## ویژگی‌ها

- پاکسازی متن فارسی
- تبدیل نیم‌فاصله به فاصله معمولی
- حذف کاراکترهای مخفی
- حذف فاصله‌های اضافه
- نمایش آمار تغییرات انجام‌شده روی متن
- فشرده‌سازی ساده کدهای CSS
- فشرده‌سازی ساده کدهای JavaScript
- اصلاح متن تایپ‌شده با کیبورد اشتباه
- دکمه‌های سریع برای کپی، پیست و پاک کردن
- حالت روشن و تاریک
- ذخیره تم انتخاب‌شده در مرورگر
- رابط کاربری راست‌به‌چپ و مناسب زبان فارسی
- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- نمایش تاریخچه تغییرات در پنجره داخلی

## کاربردها

این ابزار برای کارهای روزمره توسعه، تولید محتوا و ویرایش متن مناسب است؛ از جمله:

- پاکسازی متن‌های کپی‌شده از وب‌سایت‌ها، فایل‌های PDF یا پیام‌رسان‌ها
- حذف فاصله‌های اضافی و کاراکترهای نامرئی
- آماده‌سازی سریع متن فارسی برای انتشار
- فشرده‌سازی سریع و سبک CSS یا JavaScript
- تبدیل متن‌هایی که ناخواسته با کیبورد انگلیسی تایپ شده‌اند به فارسی

## بخش‌های ابزار

### 1. پاکسازی متن

در این بخش، متن ورودی پردازش و نسخه پاکسازی‌شده آن در خروجی نمایش داده می‌شود.

عملیات انجام‌شده:

- تبدیل کاراکتر نیم‌فاصله `U+200C` به فاصله معمولی
- حذف کاراکترهای مخفی شامل:
  - `U+200B` Zero Width Space
  - `U+200D` Zero Width Joiner
  - `U+FEFF` Byte Order Mark
- تبدیل چند فاصله متوالی به یک فاصله
- نمایش تعداد نیم‌فاصله‌های تبدیل‌شده
- نمایش تعداد فاصله‌های اضافه حذف‌شده
- نمایش تعداد کاراکترهای مخفی حذف‌شده

### 2. فشرده‌سازی کد

#### JavaScript

در حالت JavaScript، ابزار این عملیات را انجام می‌دهد:

- حذف کامنت‌های چندخطی
- حذف کامنت‌های تک‌خطی
- کاهش فاصله‌های اضافی

## رابط کاربری

رابط کاربری ابزار شامل سه تب اصلی است:

- `پاکسازی متن`
- `Minifier (CSS/JS)`
- `اصلاح کیبورد`

هر بخش شامل فیلد ورودی، دکمه اجرای عملیات، خروجی و دکمه‌های کمکی است.

دکمه‌های کمکی:

- `پاک کردن`: پاک کردن همزمان ورودی و خروجی
- `پیست`: خواندن متن از Clipboard و قرار دادن در ورودی
- `کپی`: کپی کردن خروجی در Clipboard

## حالت تاریک و روشن

ابزار از دو تم پشتیبانی می‌کند:

- حالت روشن
- حالت تاریک

کلید ذخیره‌شده:

## حریم خصوصی

این ابزار به صورت کامل در مرورگر کاربر اجرا می‌شود.

- متن‌ها به هیچ سروری ارسال نمی‌شوند.
- پردازش‌ها کاملا Local انجام می‌شوند.
- تنها داده ذخیره‌شده، وضعیت تم انتخاب‌شده در `localStorage` است.
- برای کپی و پیست از Clipboard API مرورگر استفاده می‌شود.

## سازگاری مرورگر

این ابزار در مرورگرهای مدرن قابل اجراست، از جمله:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari

> قابلیت‌های کپی و پیست مستقیم ممکن است بسته به مرورگر، سطح دسترسی و HTTPS بودن محیط محدود شوند.

## محدودیت‌ها

- Minify جاوااسکریپت به صورت ساده انجام می‌شود و Parser واقعی ندارد.
- حذف کامنت‌های JavaScript ممکن است در برخی موارد خاص مانند URLها، Regexها یا رشته‌ها نتیجه دقیق ندهد.
- ابزار فعلی خروجی را به صورت فایل ذخیره نمی‌کند.
- ابزار فعلی تنظیمات سفارشی برای نوع پاکسازی متن ندارد.
